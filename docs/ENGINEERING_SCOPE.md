# Engineering-case source coverage

The verified scope of this release is the algorithm benchmark, ablation, process, sensitivity and controlled-runtime evidence. It does not supply a runnable finite-element column model.

For the column case in Section 5, the retained manuscript reports engineering inputs and aggregate outcomes, but the following evidence has not been recovered:

1. The complete per-run column-optimization data supporting Table 13.
2. The engineering reference-front coordinates and their generation procedure for IGD.
3. The run/point identifier and rule used to select the design in Tables 14–15.
4. The executable finite-element/CAD project, loads/boundary-condition files and code-to-result lineage linking this case to the current benchmark implementation.

The manuscript's engineering tables are not included among the independently reproduced benchmark-table claims. Resolving these sources, or clearly identifying the engineering implementation and its differences in Section 5, remains a separate task. This file records data coverage and does not invent replacement experimental results.
