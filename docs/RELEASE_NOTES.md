# Proposed v1.0.0 release

This snapshot provides the implementation and run-level evidence corresponding to the manuscript data audited on 18 November 2026. It is a local release package until the authors publish it.

- Current benchmark and ablation cohorts, with shared adaptive-run mapping.
- All 15,120 unique main/ablation final sets and supplied PF10000 fronts.
- Current main/ablation feasible-run counts and CF8 shared-initialization evidence.
- Model-selection and prediction-error records, including early/late violation RMSE.
- Current CF2 visualization data, CF7 sensitivity records and 480 controlled runtime observations.
- Independent aggregation, significance, process and raw-final-set metric checks.
- Large evaluation/training histories supplied as separate `CSASS_logs_*.zip` assets.
- Third-party attribution and redistribution notices retained.

No optimization was run during preparation of this release. Engineering-case source coverage is stated separately in `docs/ENGINEERING_SCOPE.md`.
