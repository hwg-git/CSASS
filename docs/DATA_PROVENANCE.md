# Data provenance and cohort identity

The public data are assembled from the retained, audited benchmark and ablation archive and the separately returned controlled-runtime archive. The current manuscript's numerical tables are not reconstructed from historical aggregate means. Every main or ablation row points to saved run-level results and final objective arrays.

## Main comparison

- 12,960 records = 24 problems × 3 dimensions × 6 algorithms × 30 seeds.
- CSASS: 72 current-implementation settings, 2,160 runs. Its 18 adaptive ablation settings reuse 540 of these records.
- Opponents: 240 settings/7,200 retained full-campaign reproduction runs and 120 settings/3,600 Missing8-campaign runs.
- `data/Supplementary/Table_S1_Provenance_432.csv` identifies each setting's cohort and source package. Its historical-summary columns are comparison context, not original historical raw data.
- Final-set rule: all recorded true-evaluated points → constrained SPEA2 selection of at most 100 → feasible nondominated subset. The stored current final set, rather than `native_final.csv`, is the source of the reported main IGD and HV.

The retained HeEMOEA/MO-L2SMEA/PC-SAEA protocol implementations use the study's common initial sample size and evaluation budget. Their bundled vendor initializers differ: HeEMOEA/PC-SAEA normally use dimension-dependent designs and MO-L2SMEA uses 2D initial points. These are explicit protocol adaptations, not evidence that computer hardware alone explains differences from older reported values. A-NSGA-III/C-TAEA retain the reference-direction population adjustment. Read the supplied protocol sources and setting table rather than substituting a newer vendor version.

The first-submission engineering and benchmark aggregate values do not establish their exact historical raw-set extraction or whether infeasible points were included. That historical question is not asserted as solved by this release.

## Ablation and process analysis

The five modes are adaptive CSASS, RBF-only, Kriging-only, Fixed A (RBF objectives/Kriging violation), and Fixed B (Kriging objectives/RBF violation). The 90 groups cover six problems (CF2, CF7, CF8, LIRCMOP1, LIRCMOP7, LIRCMOP13), three dimensions and five modes. All 30 observations per group are retained.

`shared_adaptive_runs.csv` maps all adaptive records to main records. Controls have 2,160 separate final sets. Old conditional-finite-only aggregate files are not authoritative; the current complete-run aggregates are generated by `scripts/verify_tables.py` and supplied in `data/Recomputed/`.

The latest process analysis covers 18 adaptive problem/dimension settings. For six CF2 D=10 runs, process predictions were reconstructed from the saved evaluation history; the reconstruction provenance and final-set verification are preserved separately. Postprocessing/export failure files, where retained, do not mean that the indexed optimization run was discarded or rerun. Use the verified run index and explicit coverage report.

CF8 D=10 initialization evidence includes all 150 run/configuration combinations and the 30-seed shared-initialization summary. The supplementary trace distinguishes feasible points present in the initial sample from later true-evaluated points.

## Sensitivity and runtime

CF7 sensitivity contains 270 unique observations across nine settings. The default Pmax=20/K=10 uses the same 30 saved main CSASS records and appears in both panels of Figure 6. The other eight settings contribute 240 records. The original archive's folder name saying “NotUsedInFigure6” is obsolete; the public folder is `data/Sensitivity_CF7`.

Runtime is a separate cohort of 480 observations. `run_results_full_precision.csv` is derived from each returned `complete.json` Row with full numerical precision, not the rounded display CSV. Timing uses the frozen current CSASS core and three protocol competitors on one machine, sequentially with one compute thread. It includes initialization, search and final-set extraction, excluding indicator calculations and file output. Raw timestamps and timers are retained; elapsed timers, rather than civil-clock differences, define runtime.

## Privacy and preservation

No signature images, signed forms, private correspondence, internal review drafts or unrelated files are included. Local Windows username/machine labels in non-executable metadata are replaced by generic labels; run IDs, seeds, numerical observations and core executable source bytes are not altered. The source and public manifests document packaging changes. Copyright/attribution headers remain intact.

This package contains all final sets, not a claim that every run has a complete detailed ledger. `verification/main_run_artifact_coverage_12960.csv` lists actual availability. Extra logs are distributed as Release assets and retain their cohort directories.
