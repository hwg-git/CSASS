# 全部公共问题：6个worker运行说明

采用你选定的上一版CSASS候选算法（CF8二十维29/30次获得可行解），固定算法源代码。

## 直接启动

1. 解压整个ZIP。建议放在另一台电脑空间充足的D盘，保留所有子文件夹。
2. 打开MATLAB，将“当前文件夹”切换到包含 MAIN_CSASS_ALL.m 的文件夹。
3. 命令窗口输入：

```matlab
MAIN_CSASS_ALL
```

默认开启6个进程worker，每个worker单计算线程，完成固定清单后结束。
需要Parallel Computing、Statistics and Machine Learning、Deep Learning工具箱；缺少依赖会给出提示。启动后确认控制台显示 `ACTUAL CONCURRENCY: 6 tasks.`。

## 清单

- CF1—CF10、LIRCMOP1—LIRCMOP14。
- 维度10、20、50；每个算法每题每维度独立30次，种子1—30。
- CSASS和A-NSGA-III、HeEMOEA、MO-L2SMEA、PC-SAEA、C-TAEA，共6种算法。
- 合计24×3×6×30＝12,960次。N=100、MaxFE=500、Pmax=20、K=10。
- 延续已确认方案：三目标A-NSGA-III/C-TAEA内部实际种群91；双目标这两种算法及其他算法均100。每次真实评价严格500，包括初始评价。

## 结果位置

```text
outputs/AllBenchmarks_SelectedCandidate/tables/
```

- `RESULTS.xlsx`：逐次结果、分组汇总、统计、模型选择次数、与原论文IGD比较，以及按CF/LIRCMOP、双/三目标分开的8张IGD/HV表。
- `all_runs.csv`：每次运行的IGD、HV、种子、可行解数、耗时及实际种群。
- `complete30_summary.csv`：已齐30次的组，包含均值、标准差和失败次数。
- `paper_IGD_comparison.csv`：与原论文432个表格位置对照。
- `CF_2obj_IGD.csv`、`CF_3obj_IGD.csv`、`LIRCMOP_2obj_IGD.csv`、`LIRCMOP_3obj_IGD.csv`，以及同名HV表。
- `statistical_comparisons.csv`、`model_choice_counts.csv`：显著性及模型选择统计。

每30次完成更新CSV，每120次更新Excel，结束时再完整保存。Excel被占用时保留CSV和原始记录。原始真实评价、最终解集、模型预测和参考前沿分别保存在 `runs/` 与 `references/`，后续可重新统计，不必重跑优化。

## 暂停与继续

优先用第二个MATLAB窗口、同一当前文件夹输入：

```matlab
MAIN_CSASS_ALL('drain')
```

它会等正在计算的任务完成后停止分发。之后正常执行 `MAIN_CSASS_ALL`，自动跳过已完成任务。

若按Ctrl+C中断，先等待旧任务取消、旧并行池没有运行或排队任务，再执行：

```matlab
MAIN_CSASS_ALL('resume6')
```

它会完整归档被中断的记录，再以相同种子重启被中断任务；已完成和记录为程序失败的任务不重跑。不要删除结果或锁来强行启动，也不要同时运行两个控制器写同一个输出目录。

## 其他命令

```matlab
MAIN_CSASS_ALL('plan')       % 只看清单，零优化
MAIN_CSASS_ALL('preflight')  % 检查源代码、问题、参考前沿及依赖，零优化
MAIN_CSASS_ALL('summarize')  % 已停止时重新生成全部CSV/Excel，不重跑实验
```

## 指标与结果解释

主IGD使用保存的公共参考前沿和真实可行非支配输出；主HV以同一问题参考前沿固定归一化，参考点每个坐标1.1。逐次结果额外保存固定1.5和2.0参考点的HV供敏感性检查，均不改变优化过程。

无可行解时IGD=Inf、HV=0，属于有效记录而非程序报错。主均值保留全部30次；仅有限IGD的条件均值另列，并附有效次数。未齐30次的表格明确显示Pending，不把部分结果当作完整结果。原论文参考前沿与缺失值统计历史实现未确认，新结果按统一规则保存。

本包只涵盖公共基准；没有有限元仿真，也没有把原论文汇总数值当作新实验结果。固定清单完成即停止，不按是否接近原IGD增删种子或重复运行。

程序已在MATLAB R2023b Update1检查24个问题×3种维度的接口、两类HV、断点恢复人工案例，以及CSV/Excel和显著性导出；未在本机启动正式优化或拟合模型。完整固定运行清单另见 `EXPERIMENT_PLAN.csv`。
